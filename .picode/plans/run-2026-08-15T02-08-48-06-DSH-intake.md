## 2. 勘察摘要

### 2.1 DSH 是什么（本地勘察结论）

DSH checkout = 依赖部署根（无顶层 docs/，198 个 `@deepseek-ai/*` 包 + cordis 全家桶），能力以"capability seam"（Service Definition / Provider / Consumer）组织。关键能力包地图见附录 A。运行配置在 `~/.dsh/`（settings.yaml / profiles / agent-presets，picode-workflow 技能即作为 DSH 的 agent preset + skill 运行）。

DSH 的机制特征（与候选点对应）：

| DSH 机制 | 载体包 | 语义要点 |
|---|---|---|
| 持久 goal 跨轮 | `dsh-goal` / `dsh-goal-round-driver` / `dsh-command-goal` / `dsh-tool-goal` | 事件溯源；**激活不持久化**，`agent/session-start` 即 disarm；显式 resume 才续；回合预算（round cap）；blocked 带政策码；revision CAS 围栏 |
| 按需 skill 加载 | `dsh-skill` / `dsh-skill-filesystem` / `dsh-tool-skill` | 注册表 + provider；**渐进披露**（metadata 目录 → 按需取 body）；invocation policy（model/user 双面）；分层覆盖 |
| 后台 continuable 子代理 | `dsh-subagent` / `dsh-tool-subagent-control` / `dsh-tool-subagent-report` | one-shot vs continuable；durable descriptor；**cold resume**（从持久 session 恢复）；followup/interrupt/report 权威；子代理树枚举 |
| workflow 脚本编排 | `dsh-workflow` / `dsh-tool-workflow` | 模型写 JS 编排脚本，fan-out 子代理；parallel/pipeline；fatal 错误分级 |
| 文件沙箱+审批升级 | `dsh-fs-sandbox` / `dsh-fs-observation-policy` / `dsh-user-approval` / `dsh-permission-presets` | 每调用 mode 围栏（read-only / workspace-write / full）；越界结构化拒绝 + 同轮升级提示；**read-before-edit** 版本守卫；一次性审批瀑布（ask/never，fail-closed） |
| 后台 job | `dsh-jobs` / `dsh-jobs-local` / `dsh-tool-jobs` | 注册表：start/get/read/kill/wait；owner 隔离；流式/终态输出；完成监听 |
| 会话审计/检索 | `dsh-session-persistence` / `dsh-session-query-sqlite` / `dsh-session-telemetry` | 事件溯源持久化；SQLite FTS5 检索；遥测投影 |
| 上下文管理 | `dsh-compaction-basic` / `dsh-output-retention` / `dsh-spill` | token 计量驱动压缩；超大输出落存储定位符 |
| 其他 | `dsh-plan-mode` / `dsh-tool-todo` / `dsh-schedule` / `dsh-message-feedback` / `dsh-tool-ralph` / `dsh-time-context` / `dsh-agent-instructions` | 计划态、todo、定时提醒、逐条反馈、fresh-agent 迭代、时间上下文、AGENTS.md 加载 |

### 2.2 picode 现状对照（差距核实）

| 面 | picode 现状（已核实） | 与 DSH 的差距 |
|---|---|---|
| Goal | `goal.yaml` 文件真相（status：intake→draft→active⇄blocked→completed→cancelled；park_reason；open_questions；product_acceptance；user_confirmed_at）+ CLI `picode goal set-status / set-product-acceptance`；guardian 按 `idle_sec` 自动投喂**续跑 prompt**（`continuation.ts`，D061/D092，会话级） | 无**跨会话/跨进程** goal 激活语义（disarm/resume）；无回合预算跟踪（roundsStarted/maxGoalRounds）；无模型侧 goal 工具（pi-extension 15 工具无 goal_*）；blocked 只有自由文本 park_reason，无政策码 |
| Skills | `skills/` + SKILL.md + skill-lint（frontmatter 校验）+ `skills.ts`（D082：发现/索引/persona `skills[]` 声明接线，渐进披露**仅做到 metadata 层**进系统提示） | 无运行时**按需加载工具**（skill_load），无 invocation policy（model/user），"instructions→resources" 层未闭环 |
| 会话调度 | `sess-mgr`（17-agent-runtime：registered→sleeping⇄awake→terminated；session.yaml 落盘；guardian tick；预算 checkBudgets） | 会话恢复 = 转录+摘要重投喂（continuation.ts），**非** DSH 式 durable session cold-resume；无子代理树/followup/interrupt 权威语义 |
| 编排 | run-lead 手工编排（人设流程 P01–P16 + orchestrator 机械状态机） | 无 workflow 脚本引擎 |
| 写集/权限 | `write_paths` 静态白名单机械校验（repo_write 工具 + E2/E7 evolve 层校验 + diff 门禁）+ 人设纪律；无 session 级沙箱 mode | 无沙箱 mode 概念；越界=直接拒绝，**无升级审批流**；无 read-before-edit 版本守卫 |
| 后台任务 | 串行 merge（merge.lock）；无通用后台 job 注册表 | 无 job start/list/read/kill/wait |
| 审计 | `proc-audit` 岗（流程审计人设+红灯）+ session-audit + dashboard 只读面板 + checkpoint 只读投影（D082） | 会话事件不落库不可检索（无 FTS5 检索） |
| 证据/TDD | evidence.yaml（command+exit_code+log_ref）+ verify_commands（E4）+ 门禁矩阵 | 无"红→绿"证据化（修前失败测试记录） |

- **D036 串行 merge**、**E1–E7 进化门闩**、**R1–R10 流程硬规则**、**17 会话状态机**。
