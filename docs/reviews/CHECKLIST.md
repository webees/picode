# 审查 Checklist（审查门 · 含 ponytail 维度 PT3）

> 适用：code-review 会话 / docs/reviews/ 记录。除既有正确性/测试/文档同步/无密钥/写集边界外，增 ponytail 三维度。

## 正确性（原有）
- [ ] 行为符合目标；边界与错误路径覆盖
- [ ] 输入校验在信任边界；无数据丢失路径

## 测试可信（原有）
- [ ] 改动有测试守护；无 .only/.skip

## 文档同步（原有）
- [ ] 相关 docs/ 单源更新；DECISIONS 门禁（若涉 spec）

## 写集与安全（原有）
- [ ] 无密钥/secret 入库；diff ⊆ write_paths

## ponytail 三维度（新增，PT3）
- [ ] **死代码**：改动是否引入/遗留无引用符号、死分支、无用参数？（delete: 能删则删）
- [ ] **重复**：是否重造了代码库已有 helper/stdlib/平台原生能力？（stdlib:/native: 点名替代）
- [ ] **过度设计**：是否有单一实现接口、单一产品工厂、无调用方抽象？（yagni: 砍掉）
- [ ] ladder 对照：能否更短（一行 > 五十行）？"ponytail:" 简化标记是否已标注边界？

## 结论
- [ ] 通过 / 需修改（列出项）
