## 二、prime-agent 机制摘要（sponsor 预研，供参考；以 ind-res 取证为准）

- 定位：长时自主 coding/research agent；解决上下文丢失与任务持久化
- Continual Harness：持久状态（补充提示/记忆/技能/子 agent 规格），/refine 小步证据更新 + 快照回滚，不重写基础提示
- daemon/worker/kernel 进程隔离：会话持久、终端分离可重附、心跳/调度/持久 goal
- 子 agent 递归 = 函数调用（rlm()），agent 互发现互消息
- 自主模式：turn/token/time 预算 + 用户定义质量门
- 技能 = 可导入包，skill creator 把重复工作流沉淀为技能
